LROLRC_1001     0001    This is the first volume of LROC RDR products         
                        released from data collected during the COMMISSIONING 
                        and MAPPING mission phases. All product have been map 
                        projected using ISIS and compiled into best-effort    
                        uncontrolled mosaics.                                 

                        The WAC VIS and UV regional mosaics will be released  
                        in an upcoming update of this volume.                 

LROLRC_1001     0002    Several issues were identified during the ingestion   
                        of the RDR release into the PDS ODE syste.            

                        1) In the DSMAP.CAT, line 150-151, the "view from     
                        space" and"infinite" are quoted in a quoted string.   
                        Removed the quotes from both phrases.                 

                        2) All the detached labels in NAC_DTM have the        
                        missing "" around the ^IMAGE = pointer and missing    
                        RECORD_TYPE keyword. File names were quoted, file     
                        name case was corrected (all upper case) and the      
                        missing RECORD_TYPE keyword was added.                

                        3) The product creation date in NAC_PHOTOM.LBL has    
                        2/29 as the creation date, has a - in the name of     
                        SUB-SOLAR_AZIMUTH, it looks like there is a missing   
                        OBJECT=COLUMN statement at line 83, and it is missing 
                        the RECORD_TYPE keyword. Corrections were made to the 
                        creation date, fixing - to _ in SUB_SOLAR_AZIMUTH,    
                        added missing OBJECT = COLUMN and RECORD_TYPE         
                        keywords.                                             

                        4) A mis-match between actual column formats in       
                        INDEX/CUMINDEX tables and their respective label      
                        file.                                                 

LROLRC_1001     0003    The WAC regional multi-band (5 VIS, 7 UV/VIS)         
                        products were put into the RDR release. Browse images 
                        were also placed in the EXTRAS/BROWSE directory, one  
                        for each band, and a composite RGB.                   

LROLRC_2001     0004    The RDR VOLUME_ID has been changed from the value of  
                        LROLRC_1001 to a value of LROLRC_2001, to comply with 
                        PDS standard that VOLUME_ID values be unique. LROC    
                        CDR volumes will now have the VOLUME_ID in the form   
                        LROLRC_10xx, where xx is the release volume. LROC EDR 
                        volumes retain the VOLUME_ID in the form LROLRC_00xx. 

                        RDR products released in this volume have the keyword 
                        VOLUME_ID (with the value 'LROLRC_2001') and an       
                        updated PRODUCT_VERSION_ID (set to 'v1.1').           

                        RDR products previously released will be regenerated  
                        with labels containing the new VOLUME_ID keyword and  
                        their PRODUCT_VERSION_ID set to 'v1.1', to assist     
                        with differentiation of RDR products. Once all        
                        products have been regenerated, the old LROLRC_1001   
                        RDR volume will be removed from this archive.         

                        When importing the GLD100 PDS products into ISIS a    
                        patch released on 11/16/2011 is required ensure the   
                        correct geolocation of pixels. This patch can be      
                        download by updating your ISIS distribution using the 
                        rsync commnad. You will only need to update the base  
                        data area. See the ISIS installation guide for more   
                        information                                           
                        (http://isis.astrogeology.usgs.gov/documents/         
                        InstallGuide/index.html).
