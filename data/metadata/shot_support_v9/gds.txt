            <tr>
                <td>
                    Welcome to PDS Geosciences Node's Granular Data System MOLA PEDR Query Tool, Version 2.0.
                    Geosciences Node's Granular Data System (GDS) provides access to individual observations
                    from a selected set of PDS Data Sets.  Users select a target data set, define an area of interest, and a set of 
                    query filters, and the GDS creates a set of derived products from the observations that meet the criteria. 
                    Results can include ASCII/CSV tables, Shapefiles, and binned images. Unlike the older tools, version 2.0 
                    queries run in the background with the results emailed to the user. <b>Queries 
                    are limited to a maximum of 150,000,000 estimated individual observations</b>. Please send questions to 
                    <a href="mailto:oderest@wunder.wustl.edu">oderest@wunder.wustl.edu</a>.
                </td>
            </tr>

                <td>
                    The Mars Global Surveyor's Mars Orbiter Laser Altimeter (MOLA) instrument provides a series of laser altimetry measurements across the surface of Mars.
                    <a href="https://ode.rsl.wustl.edu/mars/pagehelp/quickstartguide/index.html?mola.htm" target="_blank">Click here to read more about MOLA.</a>
                </td>
            </tr>
            <tr>
                <td>
                    MOLA offers two key altimetry products - the PEDR and MEGDR products. MOLA PEDR products are individual altimetry readings organized along the spacecraft orbit track. 
                    The MEGDR products are PEDR products assembled into global grids referenced to Mars' center-of-mass, with resolutions up to 1/128 degree per pixel. 
                    MOLA MEGDR products will meet many user needs and should be reviewed prior to using the MOLA PEDR Query.  
                    Please see <a href="https://ode.rsl.wustl.edu/mars/indexProductSearch.aspx" target="_blank">ODE's data product search</a> for MOLA MEGDR products. 
                </td>
