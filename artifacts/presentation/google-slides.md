# Editable Google Slides

[Open the seven-slide MIMESIS pitch](https://docs.google.com/presentation/d/1KUh1zogb5VM2Cm_IDmSoIfdfhFVwX2s2HyritEfORuM/edit).

The native Google Slides deck belongs to Arjun Vijay Prakash's Google account. Its slide text is editable, using Inter Tight and Newsreader. The five supplied website screenshots retain their original pixels and use layout cropping. The displacement chart remains an image.

All seven slides were checked after import, including the slide count, text, fonts, image crops and layout. The local editable export is `mimesis-editable.pptx`; `mimesis-pitch.tex` remains the layout and content source.

Run `python scripts/build_presentation.py` from the repository root to rebuild the main PDF, editable export and standalone Beamer archive. A local rebuild does not change the Google Slides copy.
